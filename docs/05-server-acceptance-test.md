# 実機結合・受入試験手順書

作成日: 2026-10-01 / 対象: Minecraft 1.21.1、Java 21、Fabricサーバー

## 実施状態

本書は実施用の試験票であり、合格報告ではない。今回のDB結合試験ではMinecraftサーバーのFabricイベント、ネットワーク接続、Brigadierコマンドを実行していない。下表のすべてを「未実施」として納品する。サーバー起動・プレイヤー接続を伴う受入確認が完了するまでは、実機動作確認済みとは扱わない。

## 準備

テスト用ワールドと、同時接続できる異なるUUIDのプレイヤーA/Bを用意する。Java 21、Fabric Loader、対象Minecraft版に対応するFabric APIを入れる。`core/build/libs/McOdyssey-Core-0.1.0.jar` と `eco/build/libs/McOdyssey-Eco-0.1.0.jar` をmodsへ入れる。実運用ワールドで試験しない。起動・停止ログ、チャット画像、停止後のDBのコピーを証跡として保管する。

各項目は実施日時、担当、期待結果に対する実測、合否、証跡ファイルを記入する。残高は新規ワールドの場合の数値であり、先行試験で送金した分を考慮する。

## 完了判定

ST01〜ST14の基本操作が期待どおりで、ST15〜ST16の障害・切断時の挙動が記録されていること。未実施が残る場合は、その項目と理由を受入報告へ引き継ぐ。DB結合試験の合格はこの試験票の合格を代替しない。
