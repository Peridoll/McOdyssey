# McOdyssey Economy Simulator

Minecraft向けプレイヤー主導型経済フレームワーク **McOdyssey-Eco** の設計・検証用シミュレーター。

## Core idea

- JOB報酬ではなく、Minecraftアイテムそのものを資産として扱う
- サーバー在庫に応じて価格を変動させる
- 市場の不足・価格差から仕事や産業が自然発生する
- 大量生産された商品は供給増加によって価値が下がる
- 正規取引は市場統計へ反映し、非正規取引の余地も残す
- オプションの海外市場はサーバー倉庫から一定割合の商品を時間経過で消費する

## Simulator goals

- Vanilla Minecraft経済の長期シミュレーション
- プレイヤー数・IN時間分布の変更
- 採集、クラフト、加工チェーン、個人消費、在庫保有、P2P取引の再現
- 初期価格候補の探索
- 暴落、不足、裁定機会、資産格差、経済寿命の検証
- 将来的なCreate / Mekanism等のMODプリセット対応

現在は会話内で作成したPythonモデルを、再利用可能な独立シミュレーターへ整理している段階です。
